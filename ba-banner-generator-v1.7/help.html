BA Banner Generator v1.7

Converts Figma banner frames into production-ready HTML5 animated banners.

Workflow

1
Scan — click ↺ Scan to read banner frames, sections and the Control Panel.
2
Select — choose which sizes and versions to export. All are checked by default.
3
Video — if banners have a video layer, load MP4s via 📁 Project (auto) or the Video Files panel (manual).
4
Settings — set click URL, scene duration, fade time and date.
5
Convert — click Convert HTML5 Banners. Progress and warnings appear in the overlay.
6
Download — Preview Bundle for QA review · Deliverables ZIP for trafficking.

Troubleshooting

Common issues and how to fix them.

▶ Video missing from exported banner
⚠
The export log shows: ⚠ No .mp4 for funnel TOF
The banner will export with a static poster image instead of playing video.

Three ways to fix it:

1 Auto-load from project folder — click 📁 Project and pick your campaign folder. The plugin looks for optimized-videos/[vertical]/ and loads any MP4 with TOF, MOF or BOF in the filename automatically.
2 Manual per-funnel picker — in the Video Files panel, click the funnel button (TOF / MOF / BOF) and select the MP4 directly.
3 Fallback single picker — in Settings, load one MP4 that applies to all funnels.
📂
Expected folder structure for auto-load:
my-campaign/
  optimized-videos/
    casino/
      casino-tof-optimized.mp4
      casino-mof-optimized.mp4
      casino-bof-optimized.mp4

Subfolder must match the vertical name (casino, sports). Filename must contain TOF, MOF or BOF (case-insensitive).
▶ Banner not appearing in the Sizes panel

The plugin matches frames by exact pixel dimensions and a name starting with the size (e.g. 300x250_...). Check:

  • Frame width and height match a known size exactly (no decimal rounding)
  • Frame name starts with WIDTHxHEIGHT (e.g. 728x90)
  • Frame is not hidden
  • Frame lives inside a Section (or directly on the page in flat mode)
▶ Layer is hidden / missing from export

The export log will show: ⚠ Layer "Name" is hidden in frame 1. Hidden layers in the first scene frame are skipped entirely — they won't appear in any scene.

  • Make the layer visible in the first scene frame in Figma, then re-export.
  • If the layer is intentionally hidden in frame 1 but visible in later frames, it still won't export — move it to frame 1 with opacity 0 instead.

Section naming convention

Section names encode campaign type, funnel and copy code — e.g. TOF WLM · MOF OR-SC · BOF RR-500B

▶ Reference
Section nameCampaign typeFunnelCopy code
TOF WLMTargetedTOFWLM
MOF OR-SCOrganic RetargetingMOFSC
BOF RR-500BRegistered RetargetingBOF500B

No prefix = Targeted  ·  OR- = Organic Retargeting  ·  RR- = Registered Retargeting. The campaign type becomes the top-level output folder.

Output modes

Two download options — Preview for QA, Deliverables for trafficking.

▶ More info
⬇ Preview Bundle
Single self-contained preview.html — all banners inlined, open directly in any browser. Funnel tabs + copy code pills for easy navigation. Share with QA without extracting anything.
⬇ Deliverables ZIP
Each banner size as its own .zip, structured as CampaignType / Funnel / CopyCode /. Ready for ad platform trafficking. Outer ZIP named after the vertical (e.g. Casino.zip).

The ⊞ Master Preview button lets you combine Casino, Sports and Dual ZIPs into one master-preview.html with vertical tabs.
